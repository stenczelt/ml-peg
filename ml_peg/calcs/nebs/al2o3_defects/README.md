# Al2O3 Defects Benchmark

This benchmark evaluates Machine Learning Interatomic Potentials (MLIPs) on defective α-Al₂O₃ structures, focusing on dopant migration paths. It is based on the benchmark introduced in the MACE-MP-0 paper (section "Alumina defects and bulk diffusion").

## Benchmark Structure

This benchmark employs a hybrid testing strategy to evaluate both the accuracy of the potential energy surface (PES) and the model's ability to find physically realistic migration paths. It comprises two independent tests:

### 1. PES Fidelity (`test_al2o3_defects`)
- **Type**: Frozen-image evaluation (similar to `si_defects`).
- **Metric**: Force MAE (eV/Å).
- **Description**: MLIPs perform singlepoint evaluations on an archived trajectory of 139 DFT-evaluated frames (`rmse-input.xyz`). These frames contain a variety of dopant NEB images (generated by a MACE model and evaluated with CASTEP). This tests pure out-of-distribution force prediction without the computational cost of running a full DFT-in-the-loop NEB.

### 2. Path-finding stability (`test_al2o3_dopant_stability`)
- **Type**: Model-driven NEB (similar to `li_diffusion`), one test per dopant hop.
- **Metric**: NEB failure rate (fraction of hops, 0 = good, 1 = bad).
- **Description**: The 120-atom α-Al₂O₃ supercell (mp-1143 × (2,2,1)) is doped at the sites in `STABILITY_SITES` with each element in `STABILITY_DOPANTS` (default: Y at sites 0 and 12). Every in-cell neighbour within the dopant cutoff gives one hop: start = neighbour removed, end = dopant moved into the vacated site. The model relaxes both endpoints and runs a short NEB (a few steps; enough to expose blow-ups, not to converge). A hop fails if the run crashes or the barrier above the higher endpoint, `barrier - max(dE, 0)`, exceeds 5 eV. Hops are independent tests, so they can be run in parallel.

## Notes for Future Agents & Developers

If you are continuing work on this benchmark, please address the following outstanding tasks:

1. **Reconcile Frame Count**:
   - The memo notes that `rmse-input.xyz` has 139 frames, yielding an RMSE of 0.331 eV/Å. However, the published paper reports 0.35 eV/Å over 152 structures. Before finalizing this benchmark, confirm whether to use the 139-frame archive or locate the missing 13 frames to perfectly match the paper.

2. **Data Upload & CI Execution**:
   - The `rmse-input.xyz` file needs to be converted/packaged into `al2o3_defects.zip` and uploaded to the ML-PEG S3 bucket (`inputs/nebs/al2o3_defects/al2o3_defects.zip`).
   - Until it is uploaded, agents/users should place `rmse-input.xyz` directly in `ml_peg/calcs/nebs/al2o3_defects/data/` for local testing.

3. **Ordering in `calc_al2o3_defects.py`**:
   - CASTEP notoriously reorders atoms on output. The provided `rmse-input.xyz` must have its structures correctly matched (CASTEP-ordered coordinates mapped to the original elements) so that `atoms_pred.get_forces()` maps exactly 1-to-1 against `ref_forces`. Ensure this is handled natively in the `.xyz` file you provide.

4. **Documentation**:
